# Профиль голоса — пример для заполнения

Этот файл не задаёт факты продукта и не включается автоматически.
Используй его только по прямому указанию пользователя.

- Аудитория: начинающие разработчики.
- Обращение: на «ты».
- Тон: спокойный, разговорный, без фамильярности.
- Термины: «бот», «деплой», «API» допустимы.
- Эмодзи: сохранять исходные, не добавлять новые.
- Пунктуация: нормативная; тире допустимы.
- «Е/ё»: сохранять исходник, не менять имена.
- Нежелательные обороты: «выйти на новый уровень», «революционное решение».
- Пример голоса: добавьте собственный короткий образец без личных данных.
