# Проверка TextRefine RU 1.1.0

13 ноября 2026 года. После переименования проверены:

- 183 unit-теста на Windows 11 / Python 3.13.13: 182 прошли, один пропущен
  из-за отсутствия разрешения на создание символической ссылки.
- 50/50 существующих подготовленных пар: формальные проверки пройдены.
- Шесть новых демонстрационных пар из examples/quick-demo.md: извлекаемые
  защищённые данные и числа сохранены; выполнена ручная сверка утверждений.
- В двух парах есть сигналы ручного просмотра: «в случае» → «если» и
  «ориентировочная» → «примерно». Условие и степень уверенности сохранены.
- Формат Skill Creator, манифест, ссылки и синтаксис Python проходят проверки.

Демонстрационные исходники специально подготовлены для показа. Это применение
инструкций текущим ассистентом, не независимый A/B-тест двух запусков модели.
Правила редактуры не менялись. Обновлены название, идентификаторы, ссылки,
версия и шаблон запуска. Новый пакет содержит 39 разрешённых файлов с манифестом.

## Исправления

В исходном пакете на этой Windows-машине запускалось 172 теста: два падали,
один пропускался. Исправлены следующие проблемы:

- Перенаправленный UTF-8 stdin читался системной кодировкой и терял русские
  слова. Теперь для pipe используется UTF-8, включая BOM. Добавлены проверки
  кириллицы при cp1251, BOM, неверного UTF-8 и текста без замечаний.
- Тест сравнивал короткое имя Windows-пути с разрешённым полным путём.
  Теперь обе стороны приводятся к разрешённому абсолютному пути.
- Загрузчик сценариев принимал неизвестные режимы/жанры и повреждённые
  отрицательные примеры. Добавлены проверки полей, типов, кодов и согласованности.
- Trigger-файл проверялся только как JSON. Теперь проверяются структура,
  непустые уникальные запросы и логический тип `activate`.
- Подсказка запуска требовала редактуру «по-русски» при поддержке английского.
  Теперь она явно сохраняет исходный язык.
- Улучшены абзацы и перечень защищённых фрагментов в SKILL.md.

Добавлено 11 тестов. Версия оставлена 1.0.0 как подготовка к первой публикации;
изменения отмечены в CHANGELOG.md.

## Русский текст и скорость

В SKILL.md исходный ste-ru-check выдавал девять сигналов, после оформления —
шесть. Два ошибочно считают существительное «данные» канцеляритом, два
объединяют пункты списков в предложение, два принимают допустимые формулировки
за именные цепочки. Нулевого результата чекера не заявляем.
Примеры плохого текста в справочниках сохранены для объяснения правил.

Одиночный локальный замер: 1 250 байт обработаны линтером примерно за
0,0033 с, 125 000 байт — за 0,0544 с. Это не гарантия времени для всех входов
и не замер скорости модели. Ограничение входного файла — 2 МБ.

## Границы результатов

50 пар включены и в unit-тесты. Повторный запуск `run_evals.py` не добавляет
50 независимых испытаний модели. Проверялись программы и инструкции,
не процент «очеловечивания» и не превосходство над upstream.

Сверка может пропустить перестановку цен между тарифами, смену участника,
вида глагола, числа словами или нераспознаваемой единицы. Например, замена
«5 л» на «5 мл» остаётся без сигнала. Поэтому ручная сверка обязательна.

Независимый слепой A/B-тест, прогоны активации в клиентах, установка во всех
приложениях и исполнение на Python 3.10 не выполнялись. Совместимость синтаксиса
с 3.10 не заменяет запуск на этой версии.

Публикация в unit-тестах проверяется mock-подменой, без реальных записей GitHub.
После локальной проверки пакет опубликован в публичном репозитории
lev4ik52/textrefine-ru. Первый CI-прогон прошёл на Ubuntu с Python 3.10
и 3.13, но обнаружил ошибку теста на Windows: checkout и TEMP находились
на разных дисках. Исправлена подготовка относительного пути в тесте.
Повторный CI-прогон проверяется отдельно. Dry-run с `executed: false`
сам по себе не подтверждает публикацию.
