# История изменений

## 1.0.0 — 2026-11-13

Проверка перед первой публикацией на Windows:

- Исправлено чтение перенаправленного UTF-8 stdin при системной кодировке Windows.
- Исправлено сравнение путей в тесте при использовании короткого имени Windows.
- Исправлен тест относительного пути при расположении checkout и TEMP на разных дисках Windows CI.
- Добавлена проверка режимов, жанров, отрицательных примеров и trigger-сценариев.
- Уточнено оформление русских инструкций после проверки ste-ru-check.
- В подсказке запуска явно сохранён исходный язык, включая английский и смешанный текст.
- Результаты текущего прогона и ограничения приведены в TEST_REPORT.md.

Первая самостоятельная русскоязычная адаптация STE80 Humanizer 4.0.0.

- Русские правила вместо буквального переноса английских ограничений.
- Режимы light, humanize, strict и review; семь жанровых профилей.
- Двусторонняя проверка утверждений, защита цитат, данных и кода.
- Локальный диагностический CLI без зависимостей и без автоматической замены.
- Набор редакторских сценариев, негативных примеров и модульных тестов.
- Документация установки, происхождения и ограничений проверки.
- GitHub Actions и явная публикация через GitHub CLI.

Дата версии не означает, что тег или GitHub Release уже опубликованы.
