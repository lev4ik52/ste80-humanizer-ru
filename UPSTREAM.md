# Происхождение и проектные решения

Исходный проект: [Dodaios/ste80-humanizer](https://github.com/Dodaios/ste80-humanizer).
Проверенная версия: 4.0.0. Коммит: `99bc468482599f5d75f595e2c1adf893ebff4d8f`.
Дата проверки: 2026-11-13. Изучены SKILL.md, LICENSE, THIRD_PARTY_NOTICES.md и
метаданные коммита. Полного независимого аудита всех файлов источника не заявляем.

Это самостоятельная производная версия, не официальный релиз автора и не
обязательно GitHub-fork с общей историей коммитов. MIT-уведомления сохранены.

| Исходный подход | Решение в RU-версии |
|---|---|
| Два прохода и сверка фактов | Сохранены; добавлена обратная сверка новых утверждений |
| Убирать тире, если нет образца | Отменено; нормативное русское тире сохраняется |
| Структурные ограничения английского STE | Заменены русской редакционной политикой |
| Фиксированная длина предложения | Только диагностический ориентир, не запрет |
| Другие языки общим пунктом | Русский — основной; английский — отдельный облегчённый профиль |
| Признаки ИИ-письма | Контекстные редакторские риски, не атрибуция авторства |
| Некоторые примеры конкретизируют исходник | Все наши примеры сверяются на отсутствие новых фактов |
| Историческая дата как критерий авторства | Дата текста не используется для вывода об авторе |
| Обязательный отчёт после переписывания | По умолчанию только готовый текст |

Слово «80» в названии источника — историческая отсылка к его подходу, не метрика
соответствия и не процент удаления признаков. Русские ориентиры длины,
жанровые профили и состав тестов — решения этого проекта.
