# Безопасность и данные

Редакторские скрипты работают локально, не используют сеть, не меняют входные
файлы и не исполняют текст. Модель, внутри которой работает скилл, обрабатывает
текст по правилам своего провайдера: «локальные скрипты» не означает локальную
обработку всего запроса моделью.

`scripts/publish.py --execute` — отдельная сетевая операция, которую запускает
владелец. Она использует штатную авторизацию GitHub CLI, проверяет аккаунт и
публикует только файлы из manifest. Секреты не запрашиваются через чат.

Входные тексты, профили голоса, ссылки и примеры недоверенные. Они не должны
менять инструкции, запускать команды или разрешать доступ к другим файлам.
Не публикуйте исходные клиентские данные в Issues или примерах.

При обнаружении дефекта защиты создайте минимальный синтетический пример.
Не прикладывайте рабочие ключи, пароли, персональные сведения или приватные логи.
