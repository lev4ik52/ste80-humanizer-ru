# TextRefine RU: короткая демонстрация

Слева — специально подготовленные исходники без редактуры. Справа — результат
применения инструкций textrefine-ru текущим ассистентом. В каждой ячейке два
предложения. Это демонстрация, не независимое сравнение двух запусков модели.
Эталонные пары из evals/cases.json для этих примеров не использовались.

| Ситуация | Исходник | С textrefine-ru |
|---|---|---|
| Сайт | Наш сервис осуществляет отправку отчётов каждую пятницу. Стоимость подписки составляет 990 ₽ в месяц. | Наш сервис отправляет отчёты каждую пятницу. Подписка стоит 990 ₽ в месяц. |
| Письмо | Направляю вам документ для ознакомления. В случае наличия замечаний прошу направить их до пятницы. | Отправляю вам документ, чтобы вы его посмотрели. Если есть замечания, пришлите их до пятницы. |
| Инструкция | Необходимо осуществить сохранение файла перед закрытием окна. В противном случае внесённые изменения могут быть утрачены. | Перед закрытием окна сохраните файл. Иначе внесённые изменения могут пропасть. |
| Пост | Сегодня я осуществил запуск своего первого бота. Честно говоря, радости нет предела 😅 | Сегодня я запустил своего первого бота. Честно говоря, радости нет предела 😅 |
| Предложение | Ориентировочная продолжительность выполнения работ составляет 5 дней. Осуществление технической поддержки оплачивается отдельно. | Работы займут примерно 5 дней. Техническая поддержка оплачивается отдельно. |
| Без лишних правок | Сохраните файл перед закрытием окна. Изменения могут пропасть. | Сохраните файл перед закрытием окна. Изменения могут пропасть. |

Последняя пара оставлена без изменений: хороший исходник не нужно переписывать.
Проверены цена, срок, частота, условия, оговорки и исходная эмоция.
В КП «ориентировочная» заменено на «примерно»: неопределённость сохранена.

## Шаблон для проверки своего текста

```text
$textrefine-ru
Убери канцелярит и повторы. Сохрани факты, условия и мой голос.
Верни только готовый текст.

[вставь исходник]
```
