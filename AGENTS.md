# Разработка TextRefine RU

Это один переносимый Agent Skill. Главный файл — SKILL.md в корне.
Не активируйте редакторские правила для изменения самого кода автоматически.

- Держите SKILL.md короче 250 строк; примеры и подробности храните в references/.
- Приоритет: точность смысла, затем голос, затем краткость.
- Python 3.10+, только стандартная библиотека. У проверок нет сетевых вызовов.
- Не добавляйте автоматический переписчик на регулярных выражениях.
- Каждый исправленный дефект сопровождайте тестом, включая ложноположительный случай.
- Не выдавайте проверку примеров за оценку генерации моделью.
- Сохраняйте MIT-уведомления Dodaios и Siqi Chen и фиксируйте версию источника.
- Не помещайте личные тексты, логи, токены и настройки окружения в репозиторий.
- Для публикации используется явный список release-manifest.json, не вся папка.
- После изменений обновите manifest: `python scripts/validate_repo.py --refresh-manifest`.
- Запустите `python -m unittest discover -s tests -v`, `python scripts/run_evals.py`,
  `python scripts/validate_repo.py` и просмотрите git diff.
- Синхронизируйте metadata.version и CHANGELOG.md. Не публикуйте без запроса владельца.
